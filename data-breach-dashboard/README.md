# Australian Data Breach Dashboard

An interactive dashboard of notifiable data breaches reported in Australia, January 2024 to June 2026.

**Live page:** https://kishan0206.github.io/black-shard-portfolio/data-breach-dashboard/

## What it shows
- Breach notifications per half-year and per calendar year
- Top 5 sectors (Jan–Jun 2026)
- Large-scale breaches by number of people affected
- Causes of breaches (malicious attack, human error, system fault)
- Cyber incident types (phishing, ransomware, stolen credentials)
- Insights for cyber security and compliance clients

## Data
Source: Office of the Australian Information Commissioner (OAIC), Notifiable Data Breaches scheme reports and releases. The cleaned CSV files are in `data/`.
