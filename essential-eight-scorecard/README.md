# Essential Eight Readiness Scorecard

An interactive self-assessment against the Australian Signals Directorate (ASD) Essential Eight maturity model (November 2023).

**Live tool:** https://kishan0206.github.io/black-shard-portfolio/essential-eight-scorecard/

## What it does
- 46 plain-English questions across the eight mitigation strategies, each mapped to ASD's Information Security Manual (ISM) controls
- Works out the maturity level met for each strategy (0–3) and the overall level (the lowest of the eight, as ASD reports it)
- Lets you pick a target level and produces a prioritised gap report, lowest level first
- Example client, copy-to-clipboard report and print/PDF export; answers stay in the browser

## Context
ASD launched ASD Essentials in October 2026 as the evolution of the Essential Eight. ASD continues to maintain the Essential Eight during the transition, so assessments against it still stand.

This is a self-assessment aid, not a formal Essential Eight assessment.
